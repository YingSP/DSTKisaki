# 月社妃：纸上的魔法使

《饥荒：联机版》（Don't Starve Together）角色模组，为角色“月社妃（Kisaki）”提供独立的魔法值、等级成长、星座命符与功能容器系统。

> “向神发誓，我赌上一生来爱你。”

本模组不兼容单机版《饥荒》及其 DLC。

## 核心玩法

### 角色与成长

- 月社妃拥有独立的**魔法值**，用于制作和驱动模组道具；魔法值上限可随等级提高。
- 等级系统最高为 **110 级**。升级会按服务器配置提升生命、饱食、精神、减伤、伤害倍率与魔法值上限。
- 角色死亡时会损失当前累计经验的 **10%**。
- 成就系统会记录特定首领击杀；当前定义了树精守卫与蜘蛛女王相关成就。
- 默认初始物品为 `4` 张莎草纸。

### 角色特性

以下能力均可在模组配置中按需开关或调整：

- 小动物亲和、抗荆棘、武器不脱手与灵魂状态加速。
- 只食用新鲜食物及食物偏好加成。
- 制书、读书、初始科学/魔法科技与快速制作。
- 启蒙光环免疫、回精神光环、死亡掉落规则与低生命/低精神惩罚。
- 初始属性、属性成长、移速、攻击距离、火焰伤害倍率及精神影响倍率。

## 模组道具与制作

制作栏中新增“月社妃”和“星灵守护”筛选。是否允许其他角色使用模组配方由 `模组通用物品制作共享` 配置控制。

### 以太与魔法值

- **以太**是模组核心资源，可由紫宝石制作，也可消耗金块和魔法值制作。
- **以太瓶**可用于魔法盒的以太提取功能。
- 部分配方会直接消耗月社妃的魔法值。

### 容器

| 道具 | 用途 |
| --- | --- |
| 妃的杂物袋 | 基础便携式储物容器。 |
| 妃的幻想图书馆 | 便携原型机；可升级炼金、魔法、月亮、远古、暗影、辉煌、航海、制图、钓鱼、调料等科技能力。 |
| 妃的魔法盒 | 可升级解锁物品采集、捕鱼、返鲜、回耐、火焰、腐烂、快速工作、以太提取、转换、批量拆解及多种交易功能。 |
| 夜莺与黄昏之诗 | 放置式空间储物容器。 |

魔法盒与幻想图书馆的功能需消耗指定物品解锁；具体所需材料和效果以游戏内升级界面为准。全图收集功能可通过服务器配置关闭，以降低性能开销。

### 星灵守护命符

模组提供 12 个星座命符：水瓶、双鱼、白羊、金牛、双子、巨蟹、狮子、处女、天秤、天蝎、射手和摩羯。集齐全部 12 个命符后可制作“群星”命符。

不同命符提供不同的装备效果，例如移速、战斗、生存、环境适应、夜视与召唤支援等。命符配方位于“星灵守护”筛选中。

## 配置说明

服务器创建世界或设置模组时可调整：

- **模组难度**：休闲、普通、生存、挑战。
- **数据保存**：切换角色后是否保留等级、成就与技能树数据。
- **配方共享**：是否允许非月社妃角色制作模组通用道具。
- **基础属性**：生命、饱食、精神、魔法值、减伤、伤害、移速、攻击距离与对应成长值。
- **特性开关**：食物限制、读写书籍、科技、环境免疫、死亡规则、制作速度等。
- **容器功能**：是否启用全图收集。
- **开发者选项**：日志级别和调试命令；常规服务器建议保持默认关闭调试命令并使用 `ERROR` 日志级别。

## 安装与使用

1. 将模组目录放入《饥荒：联机版》的 `mods` 目录，或通过创意工坊订阅。
2. 在服务器模组列表中启用“月社妃：纸上的魔法使”。
3. 确保所有加入服务器的客户端也启用此模组。
4. 创建世界后，在角色选择界面选择“月社妃”。
5. 在制作栏的模组筛选中制作以太、命符和功能容器。

## 项目结构

```text

modinfo.lua                 模组元数据与服务器配置
modmain/common/             配方、容器、科技树、UI、钩子与 RPC
modmain/languages/          简体中文文本
scripts/prefabs/            角色、道具、命符、容器、投射物与召唤物
scripts/components/         等级、魔法值、成就与数据保存组件
scripts/kisaki_defs/        成就、动作与命符定义
scripts/widgets/            状态栏与角色信息 UI
```

## 开发说明

- 饥荒联机版的 Lua 环境基于 Lua 5.1，请避免使用更高版本 Lua 的语法和标准库特性。
- 新增物品通常需要同时补充预制体、资源、配方、本地化文本及必要的容器/UI 注册。
- 调整角色基础数值或容器升级成本时，优先检查 `modmain/common/tuning.lua`；调整服务器可见配置时修改 `modinfo.lua`。
