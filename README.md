# 月社妃：纸上的魔法使

《饥荒：联机版》（Don't Starve Together）角色模组，为角色“月社妃（Kisaki）”提供独立的魔法值、等级成长、可成长法杖、星座命符与功能容器系统。

> “向神发誓，我赌上一生来爱你。”

本 Wiki 由源码与注释整理校对而成，数据以 **v0.12**（分支 `Br_build_v1.0`）提交的实现为准。正文的数值与特性均按模组**默认配置**书写；可以自行调整的内容集中在[可配置项](#可配置项)。

> **距离单位说明**：文中的范围与距离数值均为游戏世界单位，**1 块地皮 = 4 个世界单位**（例：45 单位 ≈ 11 地皮）。

## 角色：月社妃

### 基础属性（默认配置）

| 属性 | 0 级初始值 | 每级成长 | 满级（110 级）参考值 |
| --- | --- | --- | --- |
| 生命上限 | 30 | +0.5 | 85 |
| 饱食上限 | 95 | +0.5 | 150 |
| 精神上限 | 175 | +2.5 | 450 |
| 魔法上限 | 800 | +20 | 3000 |
| 伤害倍率 | 0.3 | +0.002 | 0.52 |
| 受击吸收修正 | -0.8 | +0.01 | 0.3 |
| 移动速度倍率 | 1.08 | — | 1.08 |
| 攻击范围 | 3 | — | 3 |
| 火焰伤害倍率 | ×4 | — | ×4 |

数值说明

- **受击吸收修正**对应原版受伤吸收系数，结算时伤害乘以 `1 - 该值`，因此 `-0.8` 表示 0 级时受到 **180%** 伤害，满级 `0.3` 表示只受到 **70%** 伤害。这是角色前期脆弱的直接原因。
- **伤害倍率**对应 `combat.damagemultiplier`，0 级时只能打出 30% 伤害，随等级缓慢提升，实际输出主要依靠专属武器与命符。
- 角色对玩家造成的伤害免疫 100%（`health.playerabsorb = 1`），即 PvP 中不会受伤。
- 饥饿速率为原版威尔逊的 100%；饥饿归零后的掉血速率按初始血量换算。
- 精神方面：完全免疫怪物的疯狂光环，夜晚精神流失为原版的 **2 倍**，并免疫启蒙光环（`brightmare`、天体英雄、天体裂隙）。
- 角色**没有骨架掉落**（`skeleton_prefab = nil`），死亡时会在原地掉落 1 个复活护符（`amulet`）。

### 魔法值（魔力）

魔法值是模组专属资源，显示在状态栏三围的旁边，可点击图标查看数值、可拖拽移动位置。

**初始与上限**：当前值初始为 200，上限为 800，随等级提升（+20/级）。

**恢复与消耗**：每 1 秒结算一次净变化速率。

| 恢复来源 | 数值 |
| --- | --- |
| 角色自带回复 | +100/480 ≈ 0.208/秒 |
| 装备的精神回复（dapperness） | 按 10% 折算 |
| 周围生物 / 建筑的精神光环 | 按 10% 折算 |
| 睡眠中 | +600/60 = 10/秒 |
| 10 单位内有其他玩家 | +400/480 ≈ 0.833/秒 |
| 击杀史诗生物（`epic`） | 一次性 +该生物最大生命 / 40 |
| 进食 | 一次性 +(饱食×0.05 + 精神×0.15 + 生命×0.2) |

| 消耗来源 | 数值 |
| --- | --- |
| 潮湿 | 最多 -4/秒（随潮湿值线性增长） |
| 负面精神光环与负面装备 | 按比例扣减 |
| 模组配方与容器功能 | 按配方 / 功能定价扣除 |

**低魔法惩罚**：当前魔法值低于 100 时进入“魔力枯竭”，每 0.3 秒扣除 `饱食上限/100` 的饱食度，直到魔法值回到 101 以上。复活时若魔法值低于 100，会被直接补到 100。

### 等级与经验

- 等级上限 **110 级**，经验值由等级组件统一结算。
- 每级升级所需经验每 5 级递增一次：1~5 级每级 20，6~10 级 40，11~15 级 60，16~20 级 80，21~25 级 100，之后每 5 级递增 30~50 点不等，106~110 级每级 800。
- 累计经验参考：25 级约 1481，50 级约 6231，75 级约 15481，100 级约 30481，**满级 110 级共需 38231 点经验**。
- **每日经验上限 300 点**（BOSS 击杀经验不受该上限限制）；每天进入新的一天时重置，同时重置“今日是否已击杀 BOSS”。（按等级阶段递增上限的机制已预留，当前版本未启用。）
- 同一天内只结算 **首次** BOSS 击杀经验。

成就与等级共用“生物死亡监听 + 击杀信息防重复”机制（同一目标只结算一次）。当前已定义两项：

| 成就名 | 条件 | 监听目标 |
| --- | --- | --- |
| 堂吉诃德勇气的证明 | 击败树精守卫 | 树精 / 粗壮树精 |
| 夏洛特的网 | 击败蜘蛛女王 | 蜘蛛女王 |

成就系统框架已预留可继续扩充，但目前尚无专门的成就界面。界面上的角色信息徽章可查询等级与成就状态。

### 人物特性

以下开关特性在默认配置下的生效情况（“自带科技一本”“自动删除诅咒物”默认关闭，其余默认开启，均可逐项开关）：

- 小动物亲和：不会吓跑小动物；身边的乌鸦会自动变成金丝雀
- 食物限制：只吃新鲜食物，不吃黄色 / 红色新鲜度与腐烂的食物，也不吃怪物肉及带怪物肉词条的食物
- 食物喜好：吃零食类食物时三维收益 ×1.3，每项最多额外 +15
- 制书与读书：可以制作书籍、阅读书籍；精神崩溃时读书会立刻引来影怪
- 自带科技一本：开局自带科学一本科技（默认关闭）
- 自带魔法一本：开局自带魔法一本科技
- 抗荆棘：不受荆棘伤害
- 自动删除诅咒物（默认关闭）：进入背包的诅咒物（如猴子令牌）会被自动销毁
- 回精神光环：附近的队友每秒回复 1/12 点精神
- 快速制作：制作物品的速度更快
- 灵魂加速：死亡后的灵魂状态移速为 1.8 倍
- 死亡不掉落：死亡时不丢弃身上的物品
- 死亡掉落复活道具：死亡位置 2 秒后生成 1 个复活护符
- 武器不脱手：潮湿等情况下武器不会脱手
- 掉血惩罚：生命值越低移动速度越慢（最低约为正常的 50%）
- 低 SAN / 高启蒙惩罚：精神越低，受到的怪物疯狂光环影响越大（最多额外 +4 倍）
- 免疫启蒙光环：免疫启蒙光环的精神惩罚

不随配置变化的固定特性：

- 受到的火焰伤害为常人的 4 倍
- 免疫玩家造成的伤害（PvP 免伤 100%）
- 夜晚精神流失为原版的 2 倍
- 完全免疫怪物的疯狂光环（“低 SAN / 高启蒙惩罚”开启时会随精神下降而部分失效）
- 永不被诅咒（不会变猴，与“自动删除诅咒物”开关无关）
- 死亡不留骨架

**种植细节**：农田只接受农作物种子，普通地皮接受树种子与可部署植物，消耗背包中第一颗可用种子；种子不足时提示“无可用的种植物”，点位种满时提示“当前地皮已种满”。开关辅助功能时角色会说“已开启 / 已关闭锤铲捕锄功能”，开关状态随存档保存。

与《新生》的关系：《神曲》是无耐久的完全体——效率大幅提升（砍 1000% / 开采 1200%）、支持强力开采与远程种植、钓鱼瞬间咬钩，且无耐久限制。

- **灭火**：扑灭燃烧与闷烧中的目标；也能提前消散“唤星 / 唤月”召出的星光。失败时提示“这里没有可以熄灭的火焰。”
- **传送**：随机传送自己或目标（与原版传送法杖一致），落点两端各触发一次落雷（洞穴内改为小型地震），并增加潮湿度。锚定中的生物会被传送到锚点。
- **拆解**：按配方拆解目标物品或建筑，按其剩余耐久比例返还材料（宝石不返还，彩虹宝石例外）；对拟态物品会让其现出原形（不返还材料）。
- **瞬移**：朝鼠标落点位移，期间无敌且不受控制，落地前会再次校验落点（防止船开走后落水）。
- **唤星 / 唤月**：在落点召唤星星光源 / 极光光源，可作为临时照明（可用“灭火”状态消散）。
- **月陨**：从施法者处抛出一发月亮元素投石机弹，AOE 半径 2.5 单位（原版投石机的 2 倍），造成范围伤害并强力开采范围内可工作物、抛飞地面物品、附带相机震动。
- **影默**：同上，但为暗影元素，落点会留下原版暗影藤蔓陷阱圈。
- **影默附加效果**：装备状态下普通攻击命中会给目标叠加“纯粹恐惧”效果——目标身上周期性出现阴影之手（每 1 秒 1 次，共 7 次，最多叠 4 层，重复命中刷新持续时间），伤害由该特效自行结算。

**升级方式**：手持材料右键法杖“给予”即可投入升级材料，多给的部分会自动退还；给予无效材料或材料不足时，角色会念出完整的升级清单（含各项进度）。9 项升级全部完成后自动进化为**渡海之诗**。

### 开发说明

- 饥荒联机版的 Lua 版本为 5.1.4，请勿使用更高版本的语法与标准库特性。
- 新增物品通常需要同时补充：预制体（`scripts/prefabs/` 并在 `modmain/common/prefabs.lua` 的 `PrefabFiles` 注册）、资源（`modmain/common/assets.lua`）、配方（`modmain/common/recipes.lua`）、本地化文本（`modmain/languages/`），以及必要的容器 / UI 注册。
- 调整角色基础数值或容器升级成本时优先检查 `modmain/common/tuning.lua`；调整服务器可见配置时修改 `modinfo.lua`（修改键名需同步 `tuning.lua` 中的 `GetModConfigData`）。
- 物品的持续状态标记（是否解锁、当前状态）统一用 **tag** 表示，服务端设置后会自动同步客户端，便于双端判定；旅法杖在此基础上辅以 `OnSave/OnPreLoad` 存档与 `MOD_RPC`（法术书轮盘切换状态）。
- 护符的收纳判定统一收敛在 `utils/amuletutil.lua`（容器 `itemtestfn`、右键动作与虚拟装备激活全部经由它），修改规则只需改这一处；装备标签的容器继承由 `modmain/common/hook.lua` 对双端 `Inventory:EquipHasTag` 的增强实现。
- 全图收集等功能按周期任务扫描 `Ents`，新增相关内容时注意性能开销。
